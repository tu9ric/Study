СБОРКА И ЗАПУСК ЛАБОРАТОРНОЙ № 2

Нужны CMake, компилятор C++ с OpenMP и библиотека OpenCV.
Все команды ниже выполняй из папки lab2, где лежит этот файл.
Если сейчас находишься в lab1, сначала выполни:
cd ../lab2

1. ПОДГОТОВКА СБОРКИ

Выполни перед первой сборкой или после изменения CMakeLists.txt:
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release

Release включает оптимизацию для замеров времени.

2. СОБРАТЬ ВСЮ ЛАБОРАТОРНУЮ

cmake --build build -j

Запустить оба задания по очереди:
./build/task1/lab2_seq task1/images/2048x1536.jpg
OMP_DYNAMIC=FALSE OMP_NUM_THREADS=14 ./build/task1/lab2_omp task1/images/2048x1536.jpg
./build/task2/task2_omp

Каждую команду запускай после завершения предыдущей.

3. СОБРАТЬ И ЗАПУСТИТЬ ТОЛЬКО ЗАДАНИЕ 1

Сборка обеих версий:
cmake --build build --target lab2_seq lab2_omp -j

Последовательная версия:
./build/task1/lab2_seq task1/images/2048x1536.jpg

OpenMP, 14 потоков:
OMP_DYNAMIC=FALSE OMP_NUM_THREADS=14 ./build/task1/lab2_omp task1/images/2048x1536.jpg

Вместо task1/images/2048x1536.jpg можно указать другую картинку.
Нужен путь к файлу изображения, а не к папке images.
Каждая версия выполняет 10 повторений и выводит время в миллисекундах.
MR.yaml и result.png всегда сохраняются в lab2/task1, независимо от папки запуска.
Путь задаётся при сборке; после переноса проекта повтори подготовку и сборку.
При следующем запуске эти файлы перезаписываются.

4. СОБРАТЬ И ЗАПУСТИТЬ ТОЛЬКО ЗАДАНИЕ 2

Сборка:
cmake --build build --target task2_omp -j

Запуск:
./build/task2/task2_omp

Эта программа сама выполняет последовательное умножение и OpenMP.
После 10 повторений она выводит таблицу, как в задании 2 лабораторной № 1:
ID — номер теста, LinearTime — последовательное время в секундах,
ParallelTime — время OpenMP в секундах, Comparison — 1 при совпадении, 0 при ошибке.
Для каждого теста выводится отдельная строка. 14 потоков заданы внутри программы.
Отдельного файла task2_seq нет.

5. ПОСЛЕ ИЗМЕНЕНИЯ КОДА

Повтори команду сборки всей лабораторной или нужного задания,
затем запусти программу снова. Запускай только при успешной сборке.
Удалять папку build не нужно.
